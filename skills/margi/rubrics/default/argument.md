# Argument and reasoning

Are claims stated clearly, ordered logically and justified?

- **5**: Clear claims, explicit reasoning steps, counterarguments addressed, conclusions follow.
- **3**: The main line is traceable, but there are leaps, unstated premises or unaddressed objections.
- **1**: Assertions without reasoning, contradictions, or conclusions that do not follow.

Look for: hidden assumptions, overgeneralisation from few examples, correlation read as
causation (especially in computational results), circular definitions.
