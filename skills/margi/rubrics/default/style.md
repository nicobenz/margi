# Academic style and precision

Is the language precise, consistent and appropriate to the discipline? Judge this against
the style guide in `margi/docs/constraints.md` if one is given.

- **5**: Precise terms used consistently, appropriate register, correct citation form.
- **3**: Generally appropriate, with vague phrases, inconsistent terms or citation errors.
- **1**: Imprecise or colloquial throughout, which hinders understanding.

Point to problems; **never** supply rewritten sentences.
